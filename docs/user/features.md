# 功能说明

> **简体中文** | [English](../en/user/features.md)

## 多协议连接

LazyTerm 把字符终端和图形远程桌面放入同一个标签页与分屏工作区：

| 类型 | 主要能力 |
| --- | --- |
| 本地终端 | 通过本机 Shell 创建 PTY，支持工作目录、Shell、管理员模式和启动命令 |
| SSH | 支持密码、私钥和交互式认证路径，可关联凭据保险库 |
| AI CLI | 把用户配置的 AI 命令行工具作为普通终端会话运行 |
| Telnet | 连接兼容的 Telnet 设备或服务 |
| 串口 | 配置端口、波特率、数据位、校验位、停止位和流控 |
| RDP | FreeRDP 内嵌 Canvas；Windows 可选 MsTscAx 原生宿主 |
| VNC | 支持画面、键鼠、组合键、远端光标、剪贴板和远端尺寸调整 |

SSH、Telnet、串口、RDP 和 VNC 遇到可恢复错误时会执行带退避的自动重连。认证拒绝、证书/主机密钥问题和无效配置通常需要用户处理，不会无限重试。

## 会话树与凭据

会话树用于保存和组织常用配置：

- 使用文件夹按项目、环境或客户组织连接。
- 支持新增、编辑、复制、删除、拖拽排序、导入和导出。
- 远程配置优先通过 `credentialId` 引用凭据，不把明文密码或私钥正文写入普通会话配置。
- 凭据保险库使用 AES-GCM 加密敏感字段，并支持可选的主密码保护。
- 主密码保险库未解锁时只能查看凭据元数据，依赖这些凭据的连接无法取得密文内容。

## 标签页、分屏与工作区模板

中心工作区支持：

- 多标签页与标签拖拽排序。
- 任意层级的横向、纵向递归分屏。
- 在同一工作区混合本地终端、SSH、RDP 和 VNC 等视图。
- 面板焦点、比例调整、最大化和独立字体缩放。
- 将多面板会话组合保存为工作区模板。

活动标签页和当前分屏树只保存在运行时内存，应用重启后不会自动恢复。工作区模板是跨启动复用布局的显式机制；模板保存会话定义、树形布局、比例和焦点，但不会保存明文凭据。

## 可定制布局与视图模式

会话树、历史记录、快捷命令和 AI 助手可放置在顶部、底部或左右插槽中。插槽尺寸和模块顺序可以调整。

LazyTerm 提供三种互斥视图模式：

- `normal`：按用户配置显示全部布局区域。
- `focus`：隐藏左右插槽与底部插槽，保留标题栏和顶部标签。
- `immersive`：隐藏标题栏和所有插槽，让会话区域占满窗口。

## 终端体验

终端视图基于 xterm.js：

- 主题、字体、字号、透明度和背景图。
- 复制、粘贴、右键行为和面板级字体缩放。
- 搜索当前终端缓冲区，支持大小写、整词和正则选项。
- 命令历史、快捷命令和可选自动补全。
- 可选命令时间线，用于定位已提交命令。
- 长时间命令完成后可发送应用内或系统通知。
- 透明度或背景图启用时自动选择兼容的渲染路径。

## SFTP 文件传输

SSH 配置支持独立的 SFTP 文件操作：

- 浏览远端目录。
- 上传单个文件或批量文件。
- 下载文件或递归下载目录内容。
- 展示整体与当前文件进度。
- 取消正在进行的上传或下载。

SFTP 传输会使用对应 SSH 配置和凭据，但不依赖一个已打开的终端会话。

## 图形远程桌面

### RDP

- **FreeRDP**：画面在 LazyTerm 内嵌 Canvas 中显示，可以参与普通标签页和分屏布局。
- **MsTscAx**：仅 Windows 可用，由独立 sidecar 托管 Microsoft RDP ActiveX 控件。

两条路径共享应用级连接状态和重连策略，但画面路径不同。更多技术细节见 [RDP 架构](../developer/rdp-architecture.md)。

### VNC

VNC 使用 LibVNCClient FFI，支持区域更新、远端光标、剪贴板、文本输入、组合键、刷新请求和服务器支持时的桌面尺寸调整。

RDP/VNC 会根据焦点与可见性应用 `interactive`、`balanced`、`background` 或 `suspended` 质量预算，减少后台会话占用。

## AI 助手

AI 模块可连接 OpenAI 兼容接口：

- 配置 API 服务地址、模型和凭据引用。
- 支持流式响应、中断、重新生成和 Markdown 展示。
- 可选择是否把当前话题历史作为上下文继续发送。
- API Key 存放在凭据保险库，AI 配置不保存 Key 明文。

AI 助手不会自动获得本机终端、文件或互联网上下文；只有用户明确发送到对话中的内容才会成为模型输入。

## 配置同步与更新

- `localStorage` 是用户配置的主数据源。
- 用户可选择一个 Git 仓库，把指定配置打包为仓库根目录的 `lazy-term-config.json`。
- 同步、提交推送和拉取由用户显式触发，不是实时后台同步。
- 应用支持检查更新、下载和安装；优先访问 GitHub Releases，GitHub 超时、不可用或缺少当前平台安装包时自动回退到 Gitee 镜像。
