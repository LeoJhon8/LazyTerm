# 功能说明

## 多协议连接

LazyTerm 把多种连接类型放在统一工作区中：

- 本地终端：通过本机 Shell 创建交互式终端。
- SSH：连接远程主机，支持密码、私钥和 keyboard-interactive 等认证路径。
- AI CLI：把常用 AI 命令行工具作为终端会话管理。
- RDP：支持 FreeRDP 内嵌渲染和 Windows MsTscAx sidecar。
- VNC：支持画面渲染、输入转发和光标同步。
- 串口：连接本机串口设备。
- Telnet：连接 Telnet 服务。

## 会话树

会话树用于保存常用连接配置：

- 支持文件夹和连接节点。
- 支持新增、编辑、删除、排序、导入和导出。
- 适合按环境、项目或客户组织连接。

## 工作区

中心工作区支持：

- 多标签页。
- 树形多面板分屏，不再限制为固定两分屏。
- 标签页之间切换。
- 终端、RDP、VNC 等不同视图混合使用。

周围插槽可配置会话树、历史命令、快捷命令等模块。

## 终端体验

终端基于 xterm.js：

- 支持主题、字体、透明度和背景图。
- 支持命令历史和快捷命令。
- 支持复制、粘贴和字体缩放。
- 支持搜索当前终端缓冲区，并在匹配结果之间快速跳转。
- 背景图片或透明度启用时会自动选择更兼容的渲染路径。

## SFTP 上传

SSH 会话支持 SFTP 上传：

- 显示整体上传进度。
- 显示单文件上传进度。
- 支持取消上传。

## RDP 模式

RDP 提供多条路径：

- FreeRDP：内嵌在 LazyTerm 标签页中，适合统一工作区体验。
- MsTscAx sidecar：Windows 原生 RDP 控件宿主，适合需要 Windows 原生 RDP 能力的场景。

## 配置同步

LazyTerm 支持把主要配置同步到 Git 目录，并在设置中执行同步、提交和拉取。
