# 快捷键

> **简体中文** | [English](../en/user/shortcuts.md)

## 全局与工作区

| 快捷键 | 功能 |
| --- | --- |
| `Ctrl + T` | 新建标签页 |
| `Ctrl + W` | 关闭当前标签页 |
| `Ctrl + Tab` | 切换到下一个标签页 |
| `Ctrl + Shift + Tab` | 切换到上一个标签页 |
| `Ctrl + Shift + F` | 切换专注模式 |
| `F11` | 切换沉浸模式 |

视图模式快捷键通过 Tauri 全局快捷键注册；注册失败时会回退为应用窗口内的键盘监听。若快捷键被系统或其他应用占用，可能无法触发。

## 终端

| 快捷键 | 功能 |
| --- | --- |
| `Ctrl + F` | 打开当前终端缓冲区搜索 |
| `Ctrl + Shift + C` | 有选中内容时复制 |
| `Ctrl + Shift + V` | 粘贴剪贴板内容 |
| `Ctrl + 鼠标滚轮` | 调整当前面板的终端字体大小 |

在 macOS 上，终端搜索也接受 `Command + F`。其他快捷键是否由系统转换为 `Command` 取决于平台和 WebView 行为。

终端搜索框：

| 按键 | 功能 |
| --- | --- |
| `Enter` | 跳到下一个匹配项 |
| `Shift + Enter` | 跳到上一个匹配项 |
| `Esc` | 关闭搜索 |

搜索框还可以切换大小写敏感、整词匹配和正则表达式。

## 输入优先级

- 终端未选中文本时，`Ctrl + Shift + C` 会继续发送给终端程序，不会强制复制空内容。
- RDP/VNC 获得焦点后，部分按键与组合键会优先发送到远端。
- 浏览器、操作系统、输入法、远端应用或全局快捷键占用都可能改变最终行为。
- 右键菜单提供复制、粘贴、全选和搜索入口，可作为快捷键不可用时的替代方式。
