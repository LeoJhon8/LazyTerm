# 快捷键

| 快捷键 | 功能 |
| --- | --- |
| `Ctrl + T` | 新建标签页 |
| `Ctrl + W` | 关闭当前标签页 |
| `Ctrl + Tab` | 切换到下一个标签页 |
| `Ctrl + Shift + Tab` | 切换到上一个标签页 |
| `Ctrl + 鼠标滚轮` | 调整终端字体大小 |
| `Ctrl + Shift + C` | 复制终端选中内容 |
| `Ctrl + Shift + V` | 粘贴到终端 |
| `Ctrl + Shift + F` | 切换专注模式 |
| `F11` | 切换沉浸模式 |

说明：

- 快捷键行为可能受当前焦点、远程桌面会话或系统快捷键占用影响。
- RDP/VNC 视图中，部分组合键会优先发送给远端会话。
