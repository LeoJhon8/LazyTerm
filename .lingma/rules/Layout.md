# UI Layout Standards
- **圣杯结构固定化**:
  - **Center**: 活动会话窗口 (Terminal Emulator)。
  - **Top**: 多 Tab 页管理（支持鼠标点击切换）。
  - **Left**: 已添加的会话配置（点击即连）。
  - **Right**: 历史执行命令（点击即填/即跑）。
  - **Bottom**: 快捷命令栏（大块点击区）。
- **位置可交换性**:UI 组件必须模块化。允许通过配置文件将 `Left` 与 `Right` 互换，或将 `Bottom` 移至 `Top`。
- **拖拽缩放逻辑**:
  - 监听鼠标在边界线(Separator)上的按下并拖动事件。
  - 实现“弹性布局”：中间窗口自动填满剩余空间，四周区域记录用户手动拖拽出的宽度/高度百分比。
